Maroon Social pool

This separate browser build uses tailuge/billiards, copyright its contributors, under GNU GPL version 3. The model includes sliding, rolling, spin, ball collisions and cushion response. Maroon Social added the dark shell, scoped authoritative multiplayer adapters and build packaging.

Upstream commit: 9cd48c5cc0986f86e5514d21f7668aa408d538ea.

Browser visitors can practice locally. Maroon Social’s app can connect a short-lived, pool-only session for online opponents, accepted chat invitations and same-opponent rematches. The server validates turns and calculates physics; the browser plays its canonical replay. Existing app matches keep their original 2.x engine. This website and its GPL source are distributed separately from the Swift application; separation alone is not a legal conclusion about broader distribution obligations.
